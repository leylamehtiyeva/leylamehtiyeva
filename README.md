- Retrieval, constraint matching, and ranking

An experimental LLM agent that investigates revenue anomalies using hypothesis-driven reasoning and tool-based evidence collection.

- Hypothesis generation, testing, and verification
- Synthetic incident generation with known ground truth
- Agent traces and systematic evaluation
- Experiments exploring reasoning failures and verifier limitations

A retrieval-augmented generation project integrating Elasticsearch, OpenAI models, and tool calling.
